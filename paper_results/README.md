# Reference Paper Results

This directory contains the aggregate values reported in the manuscript.

Included files:

- `deit_budget.csv`: DeiT-S budget experiments.
- `imagenet_cnn.csv`: ImageNet CNN experiments.
- `class_skew_deit_w8a4_n128.csv`: 80/20 class-skew experiment.
- `ablation_deit_n128.csv`: ARCS ablation.
- `ece_binning_resnet18_seed1005.csv`: ECE bin-count sensitivity.
- `threshold_sensitivity_deit_w4a4_n128_seed1005.csv`: confidence-threshold sensitivity.
- `overhead_deit_w4a4_n128_seed1005.csv`: runtime and peak GPU memory.

Large logits, datasets, and model checkpoints are not stored here. CIFAR-100 values will be added after the original benchmark output files are checked against the submitted table.
